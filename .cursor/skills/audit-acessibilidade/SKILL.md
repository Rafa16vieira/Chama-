# Audit de acessibilidade

## Checklist

- [ ] Hierarquia de headings coerente
- [ ] Imagens com `alt` adequado (ou decorativas marcadas)
- [ ] Controles focáveis na ordem lógica
- [ ] Foco visível
- [ ] Labels associados a inputs
- [ ] Contraste suficiente texto/ícones
- [ ] Mensagens de erro anunciáveis
- [ ] ARIA só quando HTML semântico não basta

## Saída

```markdown
## Resumo
## Bloqueadores
## Melhorias
## Como validar
```
